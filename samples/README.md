# Sample invoice pack

These editable text fixtures mirror the PDF-shaped input expected by Ledgerline. They are intentionally synthetic.

- `invoice-1042-original.txt` and `invoice-1042-resubmitted.txt` should be flagged as a likely duplicate.
- `invoice-1043-recurring.txt` should be treated as a legitimate recurring invoice because its service period is different.

To test the harness, clone the repository, run the app, click **Import invoice files**, and select two or more files from this folder. You can edit any value, save the file, and import it again.
