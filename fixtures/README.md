# Development fixtures

This folder contains the editable source material used to regenerate the runnable samples:

- `autoparts/` contains labeled invoice sources consumed by `scripts/generate_invoice_pdfs.py` and the corpus tests.
- `inbox/` contains synthetic email bodies referenced by `samples/inbox/manifest.json`.

Reviewers who only want to run the POC can ignore this folder and use the PDFs in `samples/autoparts/pdf/`.
